**Main portfolio (latest version):** https://munibamaqsood.github.io/

## How this website works

1. **`index.html`** is the whole website. It holds the page content (HTML), the styling (CSS) and any small scripts (JavaScript).
2. **GitHub Pages** reads this repository, finds `index.html` on the `main` branch and serves it as a public website. No server or database is needed.
3. **Updating the site:** edit or upload a new `index.html` and commit it. GitHub rebuilds the site automatically within a minute or two.
4. **The link** follows the pattern `https://USERNAME.github.io/REPOSITORY-NAME/`, which is why this site lives at `/portfolio/`.
